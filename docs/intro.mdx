# Tutorial - Forums

Forums are a perfect solution to discussion boards in Discord!

## Create a new Text Channel

On the left side of the server you want to add the channel to click on the + button to create a new channel
Select the 'Forum' option and fill out the 'Channel Name' box to whatever you want the discussion to be titled
You can add an emoji for even more customization!
Toggle the Private Channel to make it hidden for most users without permissions (this can be changed later)

## Get Started Page (Optional)

Once redirected to your new channel, you will see 5 different options in a list. Click on each one to change the specific setting.
1. Permissions
2. Guidelines/Rules
3. Tags (for filtering)
4. Default Reaction
5. Make the first post!

## Create Your First Post!

Click the 'New Post' button at the top of the page
A dialogue box will open asking for a title, this is what you want your discussion response to be called
Below that you can then type whatever you want that pertains to your forum response.
You can optionally add an image to your post by clicking on the image thumbnail on the far right
To the bottom you can set an emoji to be placed upon posting, this helps promote reactions
Click the blue button that says "post" to finish!

## Post Responses

At the main forum page, you can view and click on any forum post.
With the post open, there will be a comment box in the bottom. 
After reading the post, type your response in the comment box.
i.e. the person who created the post will have an OP sticker next to their name
