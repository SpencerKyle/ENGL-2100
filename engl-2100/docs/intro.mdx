# Tutorial - Forums

Forums are a perfect solution to discussion boards in Discord!

## Create a new Text Channel
On the left side of the server you want to add the channel to click on the + button to create a new channel
Select the 'Forum' option and fill out the 'Channel Name' box to whatever you want the discussion to be titled
 You can add an emoji for even more customization!
 Toggle the Private Channel to make it hidden for most users without permissions (this can be changed later)
